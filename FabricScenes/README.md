# Fabric sample scenes

This directory is reserved for the user-authored `.fabric` scenes that will
demonstrate the M-LSD analysis and overlay nodes together with any small,
redistributable scene-owned assets they require.

Scenes will be added after the real node classes and their serialized port
contracts are stable. Codex will not generate placeholder `.fabric` files. The
samples should cover direct overlay use and reuse of the analysis outputs
independently of the overlay node. Where Fabric records an asset as an absolute
URL, the repository README will document the one-time relink step after
cloning.
